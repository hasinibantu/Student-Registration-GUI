# Student Registration GUI 🚀

This is a simple **Student Registration GUI mini project** developed using **Java AWT and Event Handling**.

## 📚 About This Project

As part of my **Java learning journey**, I came across GUI Programming and Event Handling. I found this part of Java interesting, so I decided to build a small mini project to practice what I had learned.

This project is a small step in my journey of learning Java, understanding GUI components, layouts, and event handling by building something practical. 💻✨

## ✨ Features

* Student Name input
* Roll Number input
* Branch input
* Register button
* Clear button
* Empty-field validation
* Registration success message
* User-friendly graphical interface

## 🛠️ Technologies Used

* **Java**
* **AWT (Abstract Window Toolkit)**
* **Event Handling**
* **GridLayout**
* **BorderLayout**

## 📖 Java Concepts Practiced

* Classes and Objects
* Inheritance
* Interfaces
* GUI Components
* Layout Managers
* Delegation Event Model
* ActionListener
* ActionEvent
* Event Handling

## 🖥️ How the Project Works

The application displays a student registration form where the user can enter:

1. Name
2. Roll Number
3. Branch

Clicking **Register** displays a successful registration message.

Clicking **Clear** removes all entered details.

The application also checks whether all fields have been filled before registration.

## ▶️ How to Run

Compile the Java program:

```bash
javac GUI.java
```

Run the program:

```bash
java StudentRegistration
```
